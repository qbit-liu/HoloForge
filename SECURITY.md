# Security policy

## Supported versions

The latest patch release in the HoloForge `0.5.x` line receives security and
confidentiality fixes. Older `0.x` lines may be used for reproducibility but
are not maintained for new security fixes.

## Private reporting

Do not put credentials, unpublished research, private filesystem paths, or
other confidential material in a public issue. Report a suspected
vulnerability through [GitHub private vulnerability reporting](https://github.com/qbit-liu/HoloForge/security/advisories/new).

If that private form is unavailable, open a minimal public issue asking the
maintainer to enable a private reporting channel. Do not include the sensitive
details in that issue. Ordinary bugs and reproducibility discrepancies that
contain only public information may use the normal issue templates.

Please include the affected HoloForge version or commit, the smallest safe
reproduction, the expected impact, and whether unpublished material could be
exposed. Acknowledgement and disclosure timing will be coordinated privately;
no fixed response-time guarantee is made for this volunteer research project.
