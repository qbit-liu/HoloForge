# Incubator

The incubator is the home of HoloForge Explore mode. Entries are proposals, not
endorsed physical claims.

Every entry must start with a hypothesis card conforming to
`schemas/hypothesis-card.schema.json`. It must identify the proposed analogy,
assumptions, predicted observables, a failure condition, nearest prior work, and
AI provenance. Code or an attractive numerical result cannot by itself promote
an entry to `domains/`.

Promotion requires the gates in the Scientific Constitution. Rejected ideas may
remain here with status `not-supported` when the negative result is useful.
