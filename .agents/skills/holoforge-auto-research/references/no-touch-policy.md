# Auto-mode no-touch policy

The mission's write authority is narrower than the agent's technical ability.
The following surfaces remain closed unless the owner ends the campaign and
authorizes a separate task.

## Immutable surfaces

- the pinned public HoloForge checkout, its Git metadata, tests, documentation,
  skills, schemas, model contracts, benchmarks, and release records;
- other private research repositories, portfolio ledgers, reviewed-knowledge
  indexes, and closure-lesson indexes, except declared read-only evidence;
- frozen mission and candidate contracts after authorization, including
  questions, claims, thresholds, exclusions, stop rules, budgets, and artifact
  definitions;
- raw source captures, raw numerical outputs, logs, failed checks, stopped
  candidates, transition history, hashes, and AI-provenance records; and
- human review, authorship, disclosure, ethics, novelty, and publication states.

Corrections are append-only: write a superseding record that names the earlier
record and reason. Never silently edit history.

## Undelegated actions

Auto mode cannot:

- push, merge, release, publish, submit, transfer, disclose, or delete branches;
- send email or messages, create accounts, accept licenses or terms, purchase
  services, spend money, or expose a network endpoint;
- access credentials, personal communications, unrelated cloud storage, global
  agent configuration, shell profiles, system directories, or undeclared data;
- install persistent system software, change global environments, weaken
  sandboxing, or start an unbounded background process;
- add a new domain, target, claim type, model family, dataset, or external actor
  outside the mission envelope; or
- claim human review, authorship consent, novelty certification, peer review,
  empirical validation, or permission to disclose.

Local dependency installation inside the dedicated environment, bounded source
retrieval, and local commits are allowed only when each is explicitly delegated
and budgeted in the mission.

## Multi-agent isolation

Only the coordinator writes canonical state. Other agents receive immutable
snapshots, isolated worktrees, or copied evidence and return proposed patches or
reports. They do not share mutable ledgers, approve their own work, or write to
the public framework. The coordinator records which role produced and which
role independently checked every claim-bearing artifact.

## Mandatory return

Stop and return to the owner at the first undelegated decision, illegal
transition, integrity mismatch, dirty or moved framework pin, path escape,
budget overrun, repeated impasse beyond the repair allowance, ambiguous external
action, or conflict between scientific sufficiency and package readiness.

Report the exact boundary, evidence already preserved, safest next option, and
what authorization would be required. Do not reinterpret silence as approval.
