# Benchmark development histories

This directory preserves owner-review decisions, mandatory stops, superseded
numerical routes, and negative evidence accumulated while a benchmark was
developed. These files are intentionally retained so that a concise current
contract does not erase how the accepted result was reached.

The histories are not active scientific contracts. For commands, current
acceptance gates, and present scope boundaries, use the corresponding guide
and contract in [`docs/benchmarks`](../). A later result must not be inferred
from an earlier stopped or provisional section merely because both are kept
in the same history file.
