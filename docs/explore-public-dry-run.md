**Status:** stopped at screening on 2026-08-02.

[`hypothesis-card.example.json`](../incubator/examples/hypothesis-card.example.json).

application.

| Keep/reject decision | The promotion requirements are unmet. | Do not promote; retain only as a synthetic example. |

## What the dry run verifies

The workflow does not turn a plausible analogy into a project automatically.
It stops an underspecified proposal before numerical work and records the
missing evidence. A real novel experiment should repeat these gates in a
separate private repository and remain there until its owner approves public
release.
